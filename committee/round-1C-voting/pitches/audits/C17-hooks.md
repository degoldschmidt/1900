# Hook-honesty audit — C17 The Paper Hunter
## Verdict
Honest and unusually precise about fairness, but it claims loss aversion over a dossier the player cannot see, says dread is "never resolved for free" where relief events must exist, and leaves the learning hunter's legibility unstated.
## Corrections
1. **Why it is captivating** — "a clean trail and a thin dossier are possessions" → the possession is the own-trail view, which is visible; the dossier is only inferred through windows → loss aversion attaches to what the player can see.
2. **Why it is captivating** — "dread survives forty hours because it is never resolved for free" → "dread is resolved only by priced acts — an edition, a bought clerk, a stolen page — so each resolution is an event on an institutional cadence" → tension needs relief events; unresolvable dread is chronic anxiety and churns.
3. **Why it is captivating** — "fairness attribution is the strongest predictor of persisting after loss" → add controllability: the autopsy shows the branch point (the letter that would have kept the names apart), not only the cause → persistence needs "I could have", which the worked example delivers and the argument omits.
4. **Why it is captivating / Risks** — "kept an arms race by the scepticism learner" → the learner's state must be readable through a C16 window (discarded fabrications appear in the autopsy) → a hunter that silently adapts reads as cheating.
5. **Why it is captivating** — the own-trail lag timers are not named → add: anxiety becomes anticipation because each record's arrival is a known future event → the strongest honest hook this design owns.
## Session structure
Stopping points: the register at night (costed), the quiet week before a gazette (a lull), and the arrest. Players push through because a slip is in transit, an edition is hours away, and the autopsy's branch point invites replay. They will not during lulls with no cleaning verb available, or if a capture feels caused by evidence they never saw; the own-record/window boundary must hold in code.
## Notes
"Honesty, not stimulation" is the right frame. The inverse mode as first tutorial is the best onboarding idea among the finalists: players learn fairness from the hunter's chair before they are hunted. No dark patterns found.
