# Hook-honesty audit — C17 The Paper Hunter
## Verdict
Honest and precise about fairness, but it claims loss aversion over a dossier the player cannot see, calls dread "never resolved for free" where relief events must exist, and never says the learning hunter is legible.
## Corrections
1. **Why it is captivating** — "a clean trail and a thin dossier are possessions" → the possession is the visible own-trail view; the dossier is only inferred through windows → loss aversion attaches only to what the player sees.
2. **Why it is captivating** — "dread survives forty hours because it is never resolved for free" → "dread is resolved only by priced acts (an edition, a bought clerk, a stolen page), so each resolution is an event on an institutional cadence" → tension needs relief events; unresolvable dread is chronic anxiety.
3. **Why it is captivating** — "fairness attribution is the strongest predictor of persisting after loss" → add controllability: the autopsy shows the branch point (the letter that would have kept the names apart), not just the cause → persistence needs "I could have", which the example delivers but the argument omits.
4. **Why it is captivating / Risks** — "kept an arms race by the scepticism learner" → the learner's state must be readable through a C16 window (discarded fabrications shown in the autopsy) → a silently adapting hunter reads as cheating.
5. **Why it is captivating** — the own-trail lag timers are unnamed → add: anxiety becomes anticipation because each record's arrival is a known future event → the strongest honest hook this design owns.
## Session structure
Stopping points: the night register (costed), the quiet week before a gazette (a lull), the arrest. Players push through because a slip is in transit, an edition is hours away, and the autopsy invites replay. They will not during lulls with no cleaning verb, or if a capture feels caused by evidence they never saw; the record/window boundary must hold in code.
## Notes
"Honesty, not stimulation" is the right frame. The inverse mode as first tutorial is the finalists' best onboarding idea: players learn fairness from the hunter's chair. No dark patterns found.
