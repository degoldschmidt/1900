# Project "1900"

A historically grounded spy life-sim / RPG set between 1895 and 1925, with deep systems of travel, deception, items, economy and politics; a world that moves on its own clock; a player who is hunted.

This repository currently holds the **design decision process**, run by a ten-member agentic game-design committee.

- `committee/CHARTER.md` — the brief (five base directives), the roster, rules of order, voting method
- `committee/DECISION_LOG.md` — chronological record of every decision and event
- `committee/round-1A-proposals/` — ≥10 raw proposals per panelist
- `committee/round-1B-synthesis/` — compiled pool, reviews, draft and final list of 20 candidates
- `committee/round-1C-voting/` — ballots, tally, finalist pitches
- `pitches/index.html` — the designed pitch document delivered to the owner

`1910.py` and `images/` are a 2015 prototype stub and are unrelated to the committee process.
